First-time setup

You do not need Cloudflare or GitHub for this to work. The app runs from wherever the file lives. Firebase is the only piece needed for two people to share the same numbers. GitHub Pages just gives the app a web address so a phone can open it — that part is optional but makes sharing much easier.

1 — Firebase (required for sharing)

  1. Go to console.firebase.google.com and create a project. Analytics can be off.
  2. In the left menu: Build → Realtime Database → Create Database. Pick the US region and choose Start in test mode.
  3. Copy the database URL at the top — it ends in firebasedatabase.app or firebaseio.com. Paste it into Cloud sync below and tick Sync enabled.
  4. Open the Rules tab and paste the rules below, then Publish. Test mode expires after 30 days, so this step matters.
scopes access to your root path only 

      
Be straight with yourself about what these rules do: they keep anything outside your root path locked, but anyone who has the address can read and write the tonnage numbers. That is a reasonable trade for internal scale tickets. Do not put anything sensitive in here, and pick a root path nobody would guess — something like tonnage-k4m9x2 rather than tonnage.


      
2 — GitHub Pages (optional, gives it a web address)

      
    
        
  1. On github.com create a new public repository, for example tonnage.
    2. 
        
  2. Add file → Create new file, name it index.html, paste in this whole file, and commit.
    3. 
        
  3. Settings → Pages → Source: Deploy from a branch, branch main, folder / (root). Save.
    4. 
        
  4. A minute later it is live at yourname.github.io/tonnage. Open that, finish the Firebase step, then use Copy setup link below.
    5. 
      

      
A public repo means the code is public. The code holds no data and no password — but the setup link does, so never paste that link into the repo, an issue, or a commit.


      
3 — Your crew member

      
    
        
  1. Send them the setup link. They open it once and the app connects itself.
    2. 
        
  2. They name their device, then on iPhone tap Share → Add to Home Screen, or on Android the browser menu → Install app.
    3. 
        
  3. They enter loads on the dump sheet. You see them arrive live.
    4. 
      

      
Skipping GitHub is fine too: keep the file on a shared drive and open it from there. Everything works except the update check and the one-tap setup link.

Import scale tickets

    

      
Paste CSV with a header row. Recognized columns: date, truck, tons (or lbs/pounds/weight), ticket, site, material. Trucks match on unit number.

The setup link carries the database address, root path and token in the link itself, so whoever opens it is connected with one tap — nothing to type.
